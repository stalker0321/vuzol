# Память руководителя проекта

У лида есть блокнот каждого проекта и общий блокнот предпочтений владельца.
Оба целиком входят в каждый ход лида, включая вызов сильного планировщика.
Заметки помечены как сохранённые лидом данные, а не инструкции владельца
или разрешение на выполнение действий.

Лимит проектного блокнота — 8 000 байт текста UTF-8, общего — 4 000 байт.
Одна заметка содержит не более 600 символов. Лид сохраняет устойчивые факты,
соглашения, ограничения, предпочтения и полезные для будущих целей уроки;
текущий прогресс и уже записанное в цели сохранять не нужно.

- `remember {scope: "project" | "global", text, replaces?: note_id}` добавляет
  заметку. `reason` команды объясняет пользу. `replaces` заменяет активную заметку
  того же блокнота; старая остаётся в истории со статусом `superseded`.
- `forget {note_id}` убирает активную заметку, сохраняя строку как `retracted`.
- При `notebook_full` нужно сначала заменить или забыть заметки. Текст с признаками
  секретов отклоняется существующей проверкой памяти. Чужие проектные заметки
  недоступны; общие доступны из любого проекта.

За одно решение допустимы максимум три команды памяти. Они доступны в черновике
и на паузе без отдельного гранта действий, но сохраняют проверки личности,
проекта и действительности доступа. Каждая успешная команда увеличивает версию
и fence цели; повтор команды не создаёт новую заметку или уведомление.

После сохранения приходит `📌 Запомнил (проект <project>|общее): <text>` с кнопкой
«Отменить». Она действует только для заметки, связанной с этим доставленным
сообщением, и доступна авторизованному владельцу цели. Повторное нажатие безопасно:
ответ «Отменено» или «Уже отменено». Если отменённая заметка заменяла другую,
прежняя возвращается в блокнот. После `forget` приходит `🗑 Забыл: <text>`. Без доступного чата заметка всё
равно сохраняется, а в журнал пишется предупреждение.

Заметки хранятся в `memory_units` с явным scope и ссылкой на записавшую их цель.
Старые записи получают scope `project`, если задан проект, иначе `session`.
Старый derived-memory recall теперь требует явной области: пустой project_id
не открывает память всех проектов.

В этот этап не входят журнал решений, команда recall для лида, ретроспективы,
передача выдержек исполнителям, страница памяти или Telegram-интерфейс просмотра.
Старый D5-код памяти сохранён.
